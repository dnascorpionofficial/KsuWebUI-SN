## الترجمة

توجد كافة نصوص واجهة المستخدم في `app/src/main/res/values*/strings.xml`. الإنجليزية (`values/`) هي لغة المصدر؛
بينما تمثل العربية (`values-ar`) والفرنسية (`values-fr`) والبولندية (`values-pl`) واليابانية (`values-ja`) والبرتغالية البرازيلية (`values-pt-rBR`) والصينية المبسطة (`values-zh-rCN`) ترجمات للتطبيق.

### إضافة لغة جديدة

```
python3 scripts/language_extension.py
```

يعرض اللغات التي لم تُضف بعد في قائمة مرقّمة مرتبة أبجديًا (الاسم والرمز). اكتب الرقم ثم اضغط **Enter** لإنشاء `values-xx/strings.xml` مع نسخ كل النصوص من الإنجليزية ووسمها بـ `<!-- TODO translate -->`، ثم ترجمها واحدًا تلو الآخر.
إذا لم تكن لغتك في القائمة فاكتب **`addnew`** ثم أرسل اسم اللغة ورمزها (مثل `Esperanto` و`eo`). اللغة التي أُضيفت لا تظهر في هذه القائمة؛ أما اللغة التي ما زالت فيها نصوص موسومة فتظهر تحت **Unfinished** فاخترها من هناك لمتابعة الترجمة (النصوص التي أُضيفت إلى الإنجليزية منذ ذلك الحين تُضاف أولًا).
**Enter** يتخطى النص (يبقى موسومًا)، و**`quit_translate`** يحفظ ويخرج، و**`\n`** فاصل أسطر. أبقِ المتغيرات (`%s`، `%1$d`) كما هي؛
يُرفض أي إدخال بمتغيرات مختلفة. يُحفظ كل إدخال فورًا. يلتقط البناء اللغة الجديدة تلقائيًا.

### تعديل لغة

```
python3 scripts/language_extension.py --edit
```

يعرض اللغات المضافة بالفعل (مرتبة أبجديًا، الاسم والرمز). اكتب الرقم، ثم اكتب اسم نص واحد أو أكثر (مثل `update reboot_now`) أو اضغط **Enter** لاستعراض كل النصوص.
يعرض النص الإنجليزي والنص الحالي لكل نص ويطلب نصًا جديدًا؛ **Enter** يُبقي النص الحالي.

### الفحص والتحقق

```
python3 scripts/check_strings.py
```

يعرض هذا الأمر النصوص المفقودة، وعلامات `TODO translate` المتبقية، وعدم تطابق المتغيرات، والنصوص غير المعرّفة.
يقوم الـ CI بتشغيل هذا الفحص مع خيار `--warn-only`، لذا ستظهر الملاحظات على شكل تحذيرات فقط ولن تتسبب في فشل البناء.
